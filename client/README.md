# Doctor Tracker - Client

This package contains the Next.js frontend application for Doctor Tracker.

For complete project documentation, environment setup, API contracts, testing instructions, and architecture details, please refer to the main repository documentation:

👉 **[Root README.md](../README.md)**

## Quick Start (Frontend)

```bash
# Install dependencies
npm install

# Run development server (http://localhost:3000)
npm run dev

# Run automated tests
npm test

# Run code quality checks
npm run typecheck
npm run lint
npm run build
```
